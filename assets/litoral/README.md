## Processing and reproduction

Run `node scripts/optimize-litoral.mjs` to create WebP variants at 480, 768, 1280 and 1600 px. The hero is the Porto photograph, not a synthetic coastal scene. Processing consists of resizing/compression; CSS and video apply responsive crops, scale movement and contrast overlays. No landscape features were generated or replaced. Original photographic conditions are not a promise of current weather, water conditions or access.

The page credits link to each original record and license. Remotion credits travel with the MP4 exports. Video source/reproduction: `video/litoral/README.md`. Superseded AI experiments are excluded from public/ and are not part of this deliverable.
